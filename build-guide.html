0The stack, and why GoHighLevel

Every one of the 31 videos behind the playbook builds this funnel in GoHighLevel (GHL) for the same reason we will: it holds the pages, the survey, the calendar, the CRM pipeline, email and SMS, and the automations in one login. The alternative is five tools glued together with Zapier — ClickFunnels for pages, Calendly for the calendar, HubSpot for the pipeline, Mailchimp, Twilio — each with its own bill and its own way of breaking. The cost of GHL is the learning curve; the playlists we watched exist for every step below, and they're linked where they help.

2Domain & email sending

Step 2.1 · Funnel subdomainSettings → Domains → Connect domainOwner: Jivonz + GoDaddy access
  1. Enter owners.liveluxe.com.au. GHL offers GoDaddy one-click authorisation; that only works from the GoDaddy login that holds the zone. Otherwise choose add records manually — it's one CNAME: host owners, value the target GHL shows.
  2. Verify. Then Sites → Funnels → (the funnel) → Settings → select this domain and set the VSL page as the home step (after step 9).

Do not touch

The liveluxe.com.au zone carries live Google Workspace mail. Add records only for the two subdomains below; never edit or delete the existing MX, SPF or DKIM records on the root, and never point the root domain at GHL — that would take down whatever the main domain serves and could break mail.

Step 2.2 · Dedicated sending domainSettings → Email Services → Dedicated domainOwner: Jivonz
  1. Enter lc.liveluxe.com.au (not mail. or email.). GHL lists the records: two TXT, one CNAME, two MX, one DMARC TXT — all on the lc subdomain, so they don't collide with Workspace.
  2. Add them in GoDaddy DNS, refresh until every row is green, click Verify domain.
  3. Three dots → Set headers: from name Daniel · Live Luxe, from email daniel@liveluxe.com.au. Every workflow email inherits this.

Warm-up rule

A new sending domain that blasts goes straight to spam. 300 sends on day one, doubling daily. The funnel's own volume is fine; do not import the existing owner list and email it from here in week one.

6Survey & forms

Step 6.1 · Owner surveySites → Surveys → Builder → folder "01 VSL funnel" → Add surveyOwner: Jivonz
  1. Name 01 Owner survey. Start from blank. One slide per question, in the playbook's order (own apartment → area → situation → availability → rent band → furnished → contact details last).
  2. Drag each custom field from the left panel; tick required on every slide.
  3. Conditional logic (right panel on the field): Owns apartment = No → disqualify; Area = Elsewhere → disqualify; Rent band = below David's floor → disqualify. Survey logic only branches once per question, so keep disqualifiers to these three.
  4. Last slide: first name, last name, email, phone (not required), the two consent checkboxes, with the reason line under the fields: "so we can send your earnings estimate and calendar invite".
  5. Options: on submit → redirect to URL left blank (the funnel step handles it); disqualified → redirect to the sorry page URL; progress bar on, stuck to the card; create contact on partial submission on (so an abandoned survey still gives Daniel a name to call).
  6. Styles: match the page — the accent for the button, 15px radius, 18px text.
Step 6.2 · Call feedback form (for Daniel)Sites → Forms → Builder → Add formOwner: Jivonz
  1. Name 01 Call feedback. Fields: email (system field, not required, hidden; note its query key, normally email), Call outcome (radio), Call notes.
  2. W2 will email Daniel a link to this form with ?email={{contact.email}} on the end, so the hidden field pre-fills and the submission lands on the right contact. This is the Hasib trick that means nobody has to move a card by hand after a call.

ReferenceNuno, Forms and Surveys Tips & Tricks 2025; Hasib, No-Show/Attended automatically.

10The four workflows

Automation → folder 01 VSL funnel. Build in this order; each one is a named trigger followed by actions. Start W2 and W3 from GHL's recipes (Appointment confirmation + reminder, No-show) and edit. After every edit: save, then publish.

W1 · Survey submittedTrigger: Survey submitted · survey is 01 Owner survey · disqualified = false
  1. Add tag vsl-qualified
  2. Assign to user Daniel
  3. Create/update opportunity: pipeline 01, stage New lead, name {{contact.full_name}} – {{contact.apartment_area}} – {{contact.phone}}, source Meta ads, status open, no value
  4. Send internal notification (email) to assigned user: subject "New owner lead: {{contact.full_name}}", body = every custom field
  5. Facebook Conversions API: funnel event CompleteRegistration (step 11)
  6. If/else: Available from = 6+ months → stage Nurture, add to the nurture workflow, end
  7. Wait 30 minutes
  8. If/else: contact has an appointment (condition: tag call-booked, which W2 sets) → end. Else:
  9. Update opportunity stage Qualified, not booked
  10. Email: "Saw you got to the booking page — if none of the times suited, reply and we'll find one" + booking link
  11. Wait 1 hour → SMS from Daniel with the booking link (only if service consent is ticked — add the condition)
  12. Add task to Daniel: "Call {{contact.full_name}} today"
  13. Wait 1 day → email 2 with a testimonial; wait 2 days → email 3; then add to workflow long-term nurture

Settings: allow re-entry on; stop on response on (a reply is Daniel's cue, not the machine's); auto mark as read.

W2 · Call bookedTrigger: Appointment status · confirmed · calendar 01 Daniel discovery call
  1. Add tag call-booked; remove from workflow W1
  2. Update opportunity stage Call booked
  3. Facebook Conversions API: event Schedule
  4. Email confirmation: start time {{appointment.start_time}}, who (Daniel), location {{appointment.meeting_location}}, add-to-calendar links, reschedule/cancel links ({{appointment.reschedule_link}} / {{appointment.cancellation_link}})
  5. SMS confirmation, same details, one line
  6. Wait → Event/appointment time, before 1 day → reminder email with one owner testimonial
  7. Wait → appointment time before 2 hours → SMS from Daniel by name
  8. Wait → appointment time before 15 minutes → SMS with the meeting link
  9. Wait → appointment time after 30 minutes → internal notification to Daniel: "Did {{contact.full_name}} show? Submit feedback: owners.liveluxe.com.au/call-feedback?email={{contact.email}}"

Settings: allow multiple on (an owner can rebook); stop on response off.

W3 · Cancelled or no-showTwo triggers: Appointment status cancelled · Appointment status no-show (same calendar)
  1. If/else on workflow trigger → two branches
  2. Cancelled: stage Cancelled, tag cancelled, internal notification, email "sorry you had to cancel" + reschedule link, wait 1 day → SMS, wait 3 days → email 2, then stage Lost with tag lost-cancelled
  3. No-show: stage No-show, tag no-show, internal notification, SMS within 10 minutes "we missed you — grab another time" + reschedule link, task for Daniel to call within the hour, wait 1 day → email, wait 3 days → email 2, then stage Lost
  4. Both: remove from workflow W2 first, so reminders stop
W4 · Call feedbackTrigger: Form submitted · form is 01 Call feedback
  1. If/else on Call outcome:
  2. Attended → stage Attended, add notes = {{contact.call_notes}}, task for Daniel "send agreement" due tomorrow
  3. No-show → update appointment status to no-show (this fires W3's no-show branch)
  4. Rescheduled → nothing; W2 fires again on the new booking

Two more, small

  • Stale leads: trigger Stale opportunity, pipeline 01, stage New lead or Qualified, not booked, 3 days → move to a Needs a call column and notify everyone. Moving it is what stops the trigger firing again every 3 days.
  • Won / lost: trigger Opportunity status changed to Won → send the management agreement via Payments → Documents template, internal notification to Claudia, stage Signed. Lost → remove opportunity, keep the tag.

—House rules

  • Name everything with a number prefix and keep it in folders — 01 Owner survey, 01 Daniel discovery call, 01 VSL funnel. In six months there will be twenty of each.
  • Saved is not published. Pages and workflows both have a separate publish step; "my automation isn't working" is nearly always this.
  • Never edit a query key or a system field. Make a new field.
  • Move cards with the dropdown, never drag.
  • One-way calendar sync. Two-way puts every owner's Zoom into Daniel's personal calendar as a contact and doubles the reminders.
  • Only subdomains touch GHL. The root domain's mail records are off limits.
  • Test in incognito with a real phone number before spending on ads, and after every workflow change.
  • Every form that takes a phone number has the two consent boxes and links to privacy and terms, and the phone is never required.
  • Build it, break it. Nuno's rule for learning GHL: the execution logs and the workflow Status tab tell you where a contact is stuck.
